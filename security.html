Security

The safest key store is the one that doesn't exist. Vokrew keeps your API keys on your own machine — there is no Vokrew cloud holding them, so there is no Vokrew cloud to breach.

How the bridge protects you

  • Local only. The bridge program listens on your own device (127.0.0.1). It is not exposed to your network or the internet.
  • Single-use pairing. The app pairs with a 6-digit code the bridge prints. Each code works once, expires in 10 minutes, and the bridge locks pairing after 5 wrong guesses.
  • Your keys stay put. Provider keys are stored in the bridge's configuration on your device and are used only to call the providers you chose, directly from your machine.
  • Honest stamps. Every run is stamped with the brain that served it and the tier it cost, computed from the bridge's own responses — the app can't dress up a paid call as a free one.

What this doesn't cover

Once your bridge sends a prompt to a provider you configured, that provider's security and data practices apply — pick providers you'd trust with the work you're sending. Models you run locally never leave your device. And, as with any software on your machine, keeping your own device secure is the foundation everything else stands on.

Reporting a problem

Found something that looks wrong? Tell us at github.com/vokrew — open an issue, or reach out there first if it's sensitive and we'll arrange a private channel. We'd rather hear it from you than read about it.
