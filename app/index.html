Connect to your crew

This page is a remote control — it does not run any AI itself. Your crew runs on your own machine, and this page pairs to it.

How this works

  1. Run Vokrew on your own computer first. Vokrew is a small program (the “bridge”) that talks to the AI lanes you already have — like Ollama running locally, or your own free/API lanes. Nothing runs on a Vokrew server. With Node 18+ installed, start it in a terminal: 
    git clone https://github.com/vokrew/vokrew.git
cd vokrew
node src/cli.js serve
    A one-line install is coming soon.
  2. Copy the code it prints. The bridge prints a one-time 6-digit pairing code, good for 10 minutes. There is no master code to guess — the code only exists once your bridge is running.
  3. Open this page on that same device and pair. Type the code below and tap Pair. This page connects only to the bridge on the same device (127.0.0.1:7717) — nowhere else.
  4. Then chat and run tasks. Your prompts go from this browser straight to your own bridge and your own AI. Your crew, your machine — your data stays with you.

Seeing “Can't reach your crew”? That just means no bridge is answering on this device yet — most often this page was opened on a phone with nothing running on it. Start the bridge first, on the device you want to use, then come back and pair.
